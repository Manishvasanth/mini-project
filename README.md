# 📊 Advanced Interactive EDA Dashboard

An interactive **Exploratory Data Analysis (EDA) Dashboard** built using **Streamlit**, **Plotly**, **Seaborn**, and **Pandas**. This application allows users to upload CSV or Excel datasets and perform data analysis through various interactive visualizations and statistical summaries. 

## 🚀 Features

* Upload CSV and Excel datasets
* Dataset preview and information
* KPI cards for:

  * Total Rows
  * Total Columns
  * Missing Values
  * Duplicate Records
* Interactive visualizations:

  * Histogram
  * Scatter Plot
  * Line Chart
  * Box Plot
  * Pie Chart
  * Correlation Heatmap
  * Treemap
  * Seaborn Histogram
  * Seaborn Boxplot
  * Seaborn Countplot
  * Seaborn Heatmap
* Data Types analysis
* Missing Values report
* Statistical Summary
* Download cleaned dataset as CSV 

## 🛠️ Technologies Used

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/advanced-eda-dashboard.git
cd advanced-eda-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Or install manually:

```bash
pip install streamlit pandas numpy plotly seaborn matplotlib openpyxl
```

## ▶️ Running the Application

```bash
streamlit run app.py
```

Replace `app.py` with your Python file name if different.
